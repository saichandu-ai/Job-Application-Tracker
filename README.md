# Job Application Tracker

A simple Python-based job application tracker that helps manage and monitor job applications from one place.

## Features

* Add new job applications
* View saved applications
* Update application status
* Delete applications
* Search for jobs
* Track total applications
* Store application data in a JSON file
* Simple command-line interface

## Technologies Used

* Python
* JSON
* File Handling
* Data Structures

## Project Structure

Job-Application-Tracker/
│
├── main.py
├── jobs.json
└── README.md

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python main.py
```

4. Follow the options shown in the terminal.

## Data Storage

The application stores job application details in `jobs.json`, so the data remains available when the program is run again.
